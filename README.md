# BABAHALA Group website

One static page, served by GitHub Pages at babahala.com.

`index.html` is self-contained: the styles are in the file and the only
external request is DM Sans from Google Fonts. There is no build step.
Editing the file and pushing to `main` publishes it.

The design system is the one in the slide template: DM Sans on its optical
size axis, ink #16171F, paper #F4F1EC, periwinkle #6E76F1, and the four
shape mark with its tightened spacing. The site and the client deliverables
are meant to read as one firm, so a change to one should be considered
against the other.

`robots.txt` currently asks search engines to stay away. Remove it when the
site is ready to be found.
